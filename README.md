# Student Task Management System
A Java Swing desktop application for managing student tasks through a
simple graphical user interface.

## Features

- Add tasks
- View tasks
- Search tasks
- Update task status
- Delete tasks
- Priority management
- Duplicate Task ID validation
- Input validation
- User-friendly GUI

## Technologies Used

- Java
- Java Swing
- OOP
- Collections
- ArrayList
- Exception Handling

## Project Structure

- `Task.java` - Represents the task entity
- `TaskManager.java` - Handles task management operations
- `TaskManagementGUI.java` - Provides the graphical user interface
- `Main.java` - Console entry point

## How to Run

1. Clone the repository.
2. Open the project in Eclipse.
3. Configure Java 21.
4. Run `TaskManagementGUI.java`.
5. The application opens as a desktop GUI.
